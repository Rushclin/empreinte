# Sites

One JSON file per website. Each file must follow [`../schema/site.schema.json`](../schema/site.schema.json)
and be named after the slug of its `name` (`"Hacker News"` → `hacker-news.json`).

See [CONTRIBUTING.md](../CONTRIBUTING.md) to add a site.
